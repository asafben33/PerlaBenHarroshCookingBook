## על הפרויקט

פרלה בן הראש ז״ל נולדה בקזבלנקה, גדלה במרקש, ועלתה לישראל עם לב מלא בטעמים ובסיפורים.
נישאה לאיש ממשפחת קארו — צאצאי **רבי יוסף קארו**, מגורשי קסטיליה 1492.
המטבח שלה שילב שני עולמות: **מרוקו העמוקה** ו**ספרד האנדלוסית**.

אתר זה הוא ספר בישול דיגיטלי חי, שנבנה לשמר את **1,045 המתכונים** שלה לדורות הבאים.

> *"האוכל של אמא הוא השפה שכולם מבינים — גם אלה שלא דיברו."*

## ארכיטקטורה

### SPA — Single Page Application

האתר הוא **קובץ HTML יחיד** עם Vanilla JavaScript, ללא שום Framework חיצוני.

#### Global State

| ברירת מחדל | סוג | תיאור | משתנה |
|------------|-----|--------|--------|
| `'all'` | string | קטגוריה פעילה | `ACT_CAT` |
| `[]` | string[] | קטגוריות (multi-select) | `ACT_CATS` |
| `null` | Set\|null | מזהי מתכונים (subcat filter) | `ACT_IDS` |
| `null` | string/null | חג פעיל | `ACT_HOLIDAY` |
| `'all'` | string | רמת קושי | `ACT_DIFF` |
| `''` | string | חיפוש | `SEARCH` |
| `false` | boolean | הצג מועדפים | `SHOW_FAVS` |

## מתכונים לא כשרים

קטגוריה ייעודית המכילה **40 מתכונים** שאינם כשרים לפי הלכה:

| תת-קטגוריה | מתכונים | תיאור |
|------------|---------|-------|
| פירות ים | 9 | שרימפס, קלמארי, דיונון — נמחקו מקטגוריות המקוריות |
| בשר וחלב | 31 | מתכונים ששילבו בשר/עוף עם מוצרי חלב — תוקנו במקור |

**תיקונים שבוצעו במקור:**
- חמאה → מרגרינה פרווה
- יוגורט → יוגורט סויה
- לבן → לבן סויה
- שמנת → קרם קוקוס
- גבינה → גבינת קשיו
