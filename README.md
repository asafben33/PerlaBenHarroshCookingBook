## על הפרויקט

פרלה בן ארוש ז״ל נולדה בקזבלנקה, גדלה במרקש, ועלתה לישראל עם לב מלא בטעמים ובסיפורים.  
נישאה לאיש ממשפחת קארו — צאצאי **רבי יוסף קארו**, מגורשי קסטיליה 1492.  
המטבח שלה שילב שני עולמות: **מרוקו העמוקה** ו**ספרד האנדלוסית**.

אתר זה הוא ספר בישול דיגיטלי חי, שנבנה לשמר את **1,014 המתכונים** שלה לדורות הבאים.

> *"האוכל של אמא הוא השפה שכולם מבינים — גם אלה שלא דיברו."*

## התקנה והפעלה

## הורדת תמונות

האתר עובד ללא תמונות (Fallback ל-loremflickr.com), אך לחוויה מיטבית:

```bash
python download_images.py
```

**מה הסקריפט עושה:**
- מוריד **2,298 תמונות JPG** לתיקיית `./images/`
- 270 תמונות קטגוריה (מפתחות G)
- 2,028 תמונות ייחודיות לכל מתכון (`r-{id}-1.jpg`, `r-{id}-2.jpg`)
- מדלג על תמונות שכבר הורדו
- 0.35 שניות בין הורדות (Rate limiting)
- **זמן משוער: ~15 דקות**

## ארכיטקטורה

### SPA — Single Page Application

האתר הוא **קובץ HTML יחיד** עם Vanilla JavaScript, ללא שום Framework חיצוני.

```
index.html
├── <style>          CSS (2,500 שורות) — RTL, variables, components
├── HTML structure   hero, nav, grid, modals
├── const G          ספריית תמונות (132 מפתחות)
├── const IMG        legacy aliases
├── const R[]        מערך 1,014 מתכונים
├── HOLIDAY_TAGS     מיפוי חגים → מתכונים
├── MENU_STRUCTURE   מבנה תפריט מגה-מנו
└── functions        45 פונקציות JS
```

### מבנה Recipe Object

```javascript
{
  id:    'string',         // מזהה ייחודי
  cat:   'string',         // קטגוריה (18 ערכים)
  badge: 'string',         // 'מרוקאי' | 'ספרדי' | ...
  title: 'string',         // שם המתכון
  desc:  'string',         // תיאור קצר
  time:  'string',         // זמן הכנה
  serv:  'string',         // מספר מנות
  diff:  'קל|בינוני|מתקדם',
  img:   G.key[0],         // URL תמונה
  mem:   'string',         // זיכרון מהבית
  ingr:  [{q, i}],         // מרכיבים
  steps: [{t, s}],         // שלבי הכנה
  tip:   'string?',        // טיפ של אמא
  vars:  [{title,ingr,steps}]?, // וריאציות
  tags:  string[]?         // תגיות
}
```

### מצב גלובלי

| ברירת מחדל | סוג | תיאור | משתנה |
|------------|-----|--------|--------|
| `'all'` | string | קטגוריה פעילה | `ACT_CAT` |
| `null` | string/null | חג פעיל | `ACT_HOLIDAY` |
| `'all'` | string | רמת קושי | `ACT_DIFF` |
| `''` | string | חיפוש | `SEARCH` |
| `false` | boolean | הצג מועדפים | `SHOW_FAVS` |
