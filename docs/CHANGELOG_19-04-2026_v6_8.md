## 1. תיקון #1 — Hero Tagline

### מיקום
`index.html`, שורה ~355 (CSS) — רכיב `.hero-tagline` בתוך `.hero`.

### לפני
```css
.hero-tagline {
  direction: rtl; text-align: right;
  font-size: .96rem;
  color: var(--c-gold-l);     /* זהב בהיר — מעט דהוי על הרקע הכהה */
  margin-bottom: .9rem;
  letter-spacing: .03em;
}
html.light .hero-tagline { color: #7a3a18; }
```

### אחרי
```css
.hero-tagline {
  direction: rtl; text-align: right;
  font-size: 1.15rem;          /* הוגדל מ-.96rem */
  font-weight: 700;            /* bold */
  color: #ffffff;              /* לבן ברור */
  margin-bottom: .9rem;
  letter-spacing: .03em;
  text-shadow: 0 1px 3px rgba(0,0,0,.35);  /* שיפור קריאות על רקע עם gradient/עיצוב */
}
html.light .hero-tagline {
  color: #4a2a14;              /* בנושא הבהיר שומרים על צבע כהה וקריא — לבן לא היה נראה */
  font-weight: 700;
  text-shadow: none;
}
```

### הסבר החלטות
- **1.15rem** (ולא 1.2rem ומעלה) — שמירה על פרופורציה מול כותרת h1 מעליו.
- **#ffffff** — צבע לבן מלא, הכי בולט על רקע כהה.
- **text-shadow** — לשמור על קריאות גם אם תמונת רקע עם אור זוהר.
- **light-theme override** — לא ניתן להשאיר לבן על רקע קרם; במקום זה שוחזר `#4a2a14` (חום כהה) עם אותו font-weight.

## 2. Task #2 — "Install as App" button

### סטטוס: **כבר קיים במלואו מ-v6.3.**

בדיקה שביצעתי:
- CSS: `.hdr-btn-install` מוגדר (שורה ~815) עם animation pulse עדינה.
- HTML: הכפתור בתוך `.hdr-tools`.
- JS (שורה ~7328): IIFE מלא שכולל:
  - `window.addEventListener('beforeinstallprompt', ...)` — Chrome/Edge.
  - Fallback ל-iOS (Safari לא מפעיל `beforeinstallprompt` — מוצג כפתור אחרי טעינה).
  - Hide אם ה-PWA רץ במצב standalone (כבר הותקן).
  - `localStorage` לזכור שהמשתמש דחה.
- `manifest.json` — תקין עם `name`, `short_name`, `icons` (192/512), `display: standalone`, `dir: rtl`.

**מסקנה:** לא נדרשת פעולה. הכפתור יופיע אוטומטית כאשר הדפדפן מזהה שה-PWA ניתן להתקנה.

### למה הכפתור אולי לא מופיע אצלך?
- **Chrome/Edge:** יופיע רק אחרי שביקרת באתר לפחות פעם אחת, נטעון את ה-SW, והדפדפן זיהה שאתה משתמש פעיל (engagement heuristic).
- **iOS Safari:** יופיע כעת 3 שניות אחרי load. אם דחית אותו בעבר — localStorage זוכר.
- **טיפ לבדיקה:** `DevTools → Application → Manifest → Install` (או Ctrl+Shift+A → Install).

## 4. תיקון #4 — הגדלת פונט גלובלית

### מיקום
`index.html`, שורות ~92–93 — הגדרות root של `html`.

### לפני
```css
html { scroll-behavior: smooth; }
```

### אחרי
```css
html { scroll-behavior: smooth; font-size: 17px; /* v6.8: +6% for better readability */ }
@media (max-width: 480px) {
  html { font-size: 16px; /* v6.8: mobile keeps 16px to avoid overflow */ }
}
```

### למה 17px ולא 18px או 20px
- **ברירת המחדל של הדפדפן** היא 16px ב-95% מהמקרים.
- כל מידות `rem` ב-CSS מתבססות על זה (`1rem = 16px`).
- באתר שלנו, **כל** הפונטים מוגדרים ב-`rem` (`.85rem`, `.9rem`, `1.08rem`, וכו'), וגם paddings ו-margins רבים.
- העברה ל-17px גורמת לכל הקבצים מונדנית לגדול ב-~6%.
- **18px = +12.5%** — מעט אגרסיבי. בפריסות Grid עם `grid-template-columns: repeat(auto-fit, minmax(220px, 1fr))`, הטקסט בכותרות הכרטיסים יכול "לצאת" מהכרטיס.
- **17px = +6%** — משמעותית לקריאות, שקולה מבחינת פריסה.

### למה מובייל נשאר 16px
במסכי טלפון (≤480px), ה-grid עובר ל-`1fr` (טור אחד), וה-padding/font trade-off הופך להיות רגיש. הפסקה של 17px במסך 375px רוחב יכולה לגרום לאובדן 2-3 שורות נראות במסך. 16px במובייל + 17px בדסקטופ = פשרה אופטימלית.

### שיפור נוסף: `.book-p`

```css
/* לפני */
.book-p { ... font-size: .92rem; color: rgba(237,224,196,.85) }

/* אחרי */
.book-p { ... font-size: 1.02rem; color: rgba(237,224,196,.9) }
```

פסקאות הספר (`book_data.js`) הן טקסטי קריאה ארוכים — עד 200 מילים לפסקה, בעברית, עם line-height 1.95. הגדלה מ-`.92rem` (= 15.64px @ 17px base) ל-`1.02rem` (= 17.34px @ 17px base) **+ העלאת opacity מ-.85 ל-.9** נותנת קריאות משמעותית יותר טובה לטקסטים הארוכים מהספר "על שביל האהבה ממרוקו לירושלים" שמוצגים בדף ה-"אודות".

### מה לא שיניתי במכוון
- **Headers (h1/h2/h3)** — כבר גדולים עם `clamp(min, viewport-unit, max)`. הגדלה נוספת הייתה עלולה לשבור title-overflow.
- **כפתורים, nav, categories** — נשארו בגדלים היחסיים שלהם; ה-6% הגלובלי מספיק.
- **Modal body text** — כבר ב-`1rem` ויותר; הגדלה גלובלית טיפלה בזה טוב.
- **Grid card titles** — יש להם `font-size` מפורש; גדלו ב-6% פרופורציונלית עם ה-root font.
