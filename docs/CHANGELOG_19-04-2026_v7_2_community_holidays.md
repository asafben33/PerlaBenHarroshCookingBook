## מה בוצע

### 1. `COMMUNITY_HOLIDAY_TAGS` — מבנה תיוג חדש ב-data.js

קבוע חדש שממפה **עדה × חג ← מתכונים מסורתיים**:

```javascript
const COMMUNITY_HOLIDAY_TAGS = {
  iraq: {
    shabbat: ['iq1','iq2','iq4','iq8','iq10','iq13','iq14','iq21','iq28'],
    rosh:    ['iq6','iq8','iq11','iq25','iq30'],
    pesach:  ['iq5','iq8','iq14','iq19','iq20','iq24'],
    // ...
  },
  // ... 8 more communities
}
```

**9 עדות × 10 חגים = 90 שילובים אפשריים.**

### 2. תפריט חדש: כל עדה → "כל המתכונים" + "חגי העדה" → 10 חגים

ב-MENU_STRUCTURE, כל עדה הפכה ל-accordion עם:

```
עדות ישראל
├── עיראק
│   ├── כל המתכונים (30)
│   └── חגי העדה
│       ├── שבת (9)
│       ├── ראש השנה (5)
│       ├── יום כיפור (4)
│       ├── פסח (6)
│       ├── מימונה (0) ← אפור, "אין מתכונים"
│       ├── חנוכה (2)
│       ├── פורים (3)
│       ├── שבועות (3)
│       ├── סוכות (4)
│       └── חינה (2)
├── כורדיסטן
│   ├── כל המתכונים (30)
│   └── חגי העדה ← (אותו מבנה)
└── ... (אשכנז, תימן, פרס, בוכרה, טוניסיה, טורקיה, מטבח ישראלי)
```

### 3. עיצוב מובחן לכפתורי חגים

`.pc-comm-hol` — כפתור ייעודי בגוון אדום-אלמוגי (`#d4603a`) שמבחין בין:
- **חגי העדה** (אדום-אלמוגי, מודגש) ← מסורת תרבותית
- **קטגוריות רגילות** (זהב, רגוע) ← מתכון לפי סוג

חגים ללא תיוגים (כמו "מימונה" שאינה מסורתית מחוץ לעדות מרוקו/לוב) מופיעים **חצי-שקופים עם cursor: help** ונותנים toast: "אין עדיין מתכונים מתויגים לחג זה בעדה הזו".

### 4. JS: `selectCommunityHoliday()` + branch ב-`buildPanel`

לחיצה על חג של עדה מפעילה:
```javascript
selectCommunityHoliday(community, holidayKey, label, groupKey)
  → showMainGrid()
  → ACT_IDS = new Set(COMMUNITY_HOLIDAY_TAGS[community][holidayKey])
  → renderGrid()  // מסנן רק את המתכונים המתויגים
  → sec-title = "עיראק — פסח"
```

## כיסוי תיוג — שקיפות מלאה

זהו **תיוג ראשוני מבוסס מקורות מתועדים**, לא ידע משפחתי אישי:

| עדה | תיוגים יחודיים | תיוגים בסה"כ |
|---|---|---|
| עיראק | 27 / 30 | 38 |
| כורדיסטן | 25 / 30 | 36 |
| אשכנז | 23 / 30 | 36 |
| תימן | 25 / 30 | 42 |
| פרס | 23 / 30 | 43 |
| בוכרה | 22 / 30 | 40 |
| טוניסיה | 24 / 30 | 41 |
| טורקיה | 29 / 30 | 53 |
| מטבח ישראלי | 23 / 30 | 41 |
| **סה"כ** | **221 / 270** | **370** |

**82% כיסוי** — מתכונים שלא תויגו הם בעיקר תבשילי-יומיום שאינם משויכים לחג ספציפי (סלטים, חמוצים, ירקות מבושלים).

### לוגיקת התיוג שהפעלתי

- **שבת** — תבשילי-בישול-איטי, חמין, מאפים מסורתיים, לחמים מיוחדים
- **ראש השנה** — מתכונים מתוקים (סימני שנה טובה), דבש, רימון, שזיף, גזר
- **יום כיפור** — מרקים קלים לערב צום ולשובר צום
- **פסח** — בלי קטניות (אשכנז) / עם אורז (ספרדים), פחה, קוסקוס מצה-תחליף
- **מימונה** — **רק טוניסיה ואין במתכוני העדות עוד** (קלאסי מרוקאי, וזה כבר בקטגוריה "מרוקו → חגים")
- **חנוכה** — מטוגנים בשמן, סופגניות, לביבות, בורמואלוס, ספינג'
- **פורים** — מתוקים למשלוח-מנות, בקלאוה, חלבה, ריבות
- **שבועות** — חלבי, גבינות, מאפי גבינה, בורקס/בויוס, שיר-ברנג'
- **סוכות** — תבשילים גדולים לאירוח, עלי-גפן ממולאים, ירקות עונה
- **חינה** — מתוקים מיוחדים לטקס שלפני חתונה (תימן, טוניסיה, בוכרה, פרס)

### למה אני שקוף לגבי זה

הכרתי אישית כששני אתה ביקשת — לא הייתי בטוח אם לעשות את זה כי **תיוג חגים אותנטי הוא ידע משפחתי שיש בו וריאציות**. למשל: בוטרגה (טונה מיובשת) בטוניסיה — חלק מהמשפחות מגישות בראש השנה כסימן לפריון, חלק רק בשבתות. בחרתי בגישה שהוגנת לרוב המשפחות, מבוססת על מקורות מתועדים על מטבח יהודי-ספרדי/מזרחי/אשכנזי.

**אם אתה (או בני המשפחה) רואים שילוב לא נכון או שחסר מתכון מסורתי במשפחה שלכם — תגיד לי ואני אתקן בהקלה.** ה-COMMUNITY_HOLIDAY_TAGS הוא מילון פשוט שאפשר לערוך ידנית בקלות.
