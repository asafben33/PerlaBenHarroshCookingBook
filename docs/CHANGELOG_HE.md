# שינויים — אפריל 2026

## index.html

### 1. העברת "אודות" ל-Hero (כותרת + תמונה + פסקאות)
- **נוסף:** `<section id="bio">` מיד אחרי `<section class="hero">`. מכיל את כותרת "פרלה ופנחס בן הראש ז״ל — המשפחה שיצבה מטבח", תמונת החתונה (base64 ללא שינוי), פסקת ההקדשה (`about-memorial`), ושתי פסקאות `about-p`.
- **הוסר:** כפתור "קרא עוד על פרלה ופנחס בן הראש ז״ל" מתוך Hero.
- **הוסר:** `<section id="about" class="about" aria-hidden="true">` הישן. תוכנו פוצל ל-`#bio` (למעלה) ול-`#book-wrapper` (שומר על `<div id="book-content"></div>` ועל תגיות `about-tags`).
- **הקוד של `toggleAbout()` נשאר** (מוגן ב-`if (!sec) return;`) — לא עושה כלום ללא ה-section הישן, לא קורס. ניתן להסיר בהמשך.

### 2. CSS חדש
- `.bio`, `.bio-inner`, `.bio-media` — ריווח, flex layout, responsive ל-mobile (`@media max-width 620px` → stacked וממורכז).
- `.book-chapter` — נוסף `max-width: 820px; margin: 0 auto;` (חיזוק, מונע "בריחה" של טקסט פרקים שהיה בצילום המסך עם החץ האדום).
- `.book-sub-block` — wrapper לכל תת-סעיף בפרקי הספר.
- `.book-inline-photo` — תמונות משובצות בתוך פרקי הספר (רוחב 460px, caption תחתון, hover zoom).
- Helpers טיפוגרפיים (במקום inline style): `.book-verse`, `.book-signature`, `.book-quote`, `.book-the-end`, `.book-source`.
