# CHANGELOG — v7.1: רשת מתכונים מוסתרת בטעינה (Hotfix UX)

## הבעיה

אחרי פריסת v7.0, הדף הראשי הציג את כל 1,054 המתכונים מייד בטעינה — מתחת ל-Hero וה-Bio. זה גרם למצב הבא:

1. הדף ארוך מדי בטעינה ראשונית
2. המשתמש שלא ביקש לראות מתכונים עדיין מוצף בהם
3. הסתיר את חלקי המידע שהוא כן רצה (ספר, אודות) מתחת לכמות ענקית של כרטיסי מתכונים

## הפתרון

**רשת המתכונים מוסתרת בברירת מחדל** ומופיעה רק אחרי פעולת משתמש מפורשת:
- לחיצה על כל קטגוריה בתפריט הניווט
- חיפוש במילת חיפוש (כל תו)
- לחיצה על כפתור "עיון במתכונים" ב-Hero

הדף הראשי בטעינה כעת קצר ונקי:
```
Header → Hero (עם CTAs) → Bio → [רשת מוסתרת] → Book → About-redesigned
```

### HTML (שורה 1720 — באלמנט `<main>`)
```html
<!-- v7.1: class="main-hidden" -->
<main id="main" class="main-hidden" role="main" aria-hidden="true">
```

### JS — פונקציות גלובליות חדשות (שורה 7774)
```javascript
function showMainGrid() {
  var m = document.getElementById('main');
  if (m) { m.classList.remove('main-hidden'); m.setAttribute('aria-hidden', 'false'); }
}
function hideMainGrid() {
  var m = document.getElementById('main');
  if (m) { m.classList.add('main-hidden'); m.setAttribute('aria-hidden', 'true'); }
}
```

### JS — חיווט ל-5 נקודות כניסה

**1. `selectCat` (בתוך buildNav):** קריאה ל-`showMainGrid()` בתחילת הפונקציה.

**2. `selectMulti` (בתוך buildNav):** קריאה ל-`showMainGrid()`.

**3. `selectByIds` (בתוך buildNav):** קריאה ל-`showMainGrid()`.

**4. `doSearch` (גלובלית):**
```javascript
if (SEARCH) showMainGrid();  // empty search doesn't hide once revealed
```

**5. Hero CTA "עיון במתכונים":** במקום גלילה בלבד, כעת מבצע לחיצה על כפתור "הכל" בתפריט:
```javascript
var allBtn = document.querySelector('#cat-inner .nb[data-nav-key="all"]');
if (allBtn) allBtn.click();  // triggers selectCat('all') which shows grid
```
