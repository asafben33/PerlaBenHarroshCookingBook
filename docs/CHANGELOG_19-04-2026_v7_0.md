## סקירה כללית

v7.0 מבצע שיפוץ ארכיטקטוני של הדף הראשי. זהו הבסיס שיאפשר את שלב 2 (audit_recipes.py) ושלב 3 (תיקון מתכונים ספציפיים). 4 שינויים מבניים בוצעו ב-commit אחד גדול בהתאם לבקשת המשתמש.

**שלב 1 לא נוגע בתוכן המתכונים** — לא שונה שם, מרכיב, שלב, תמונה או הערת זיכרון של אף מתכון מתוך ה-1,054.

## 4 שינויים מבניים

### 1. Header מאוחד

הוסף `div.hdr-brand-v7` לפני שורת החיפוש. מציג:
- **שם האתר** — "ספר הבישול של פרלה" (Frank Ruhl Libre, 1rem, זהב בהיר)
- **ספירה דינמית** — "1,054 מתכונים" (עודכן ב-init מתוך `R.length.toLocaleString()`)
- קו מפריד דק (border-inline-end זהוב)
- Responsive: במובייל (≤640px) ה-count מוסתר, והכותרת מתכווצת ל-0.88rem

**i18n:** `site_name_short`, `recipes_label`

### 2. Hero מקוצר עם CTA

- הוסרו: `.hero-pills`, `.hero-about-btn` (כבר לא היו קיימים בקובץ v6.10 בפועל)
- נוספה שורת 2 כפתורים (`.hero-cta-row`):
  - **עיון במתכונים** (ראשי, רקע `--c-spice` אדום-חרדל) → גלילה אל `#main`
  - **קרא את הספר** (משני, תחום זהב) → גלילה אל `#book-wrapper` + הפעלת `#book-toggle`
- Hover: `transform: translateY(-1px)` + שינוי רקע

**i18n:** `hero_cta_browse`, `hero_cta_book`

### 3. סדר החלקים — Main עלה למעלה

**לפני** (v6.10):
```
Hero → Bio → Book-wrapper → About-redesigned → Main (רשת מתכונים)
```

**אחרי** (v7.0):
```
Hero → Bio → Main (רשת מתכונים) → Book-wrapper → About-redesigned
```

המשתמש מגיע לרשת המתכונים מייד אחרי הביוגרפיה הקצרה, במקום אחרי 2 סעיפים ארוכים. הספר והסעיף המורחב "על שביל האהבה" נשארים גלויים למי שרוצה לקרוא.

### 4.1 Option C — חגי העדות כ-container ריק

תחת "עדות ישראל" נוסף כפתור `.pc-holidays.pc-placeholder` עם העיצוב האדום-חרדל האמור במוקאפ:
```
{placeholder:'communityHolidays', lbl:'חגי העדות (בקרוב)',
  emptyMsg:'מתכונים לחגי העדות יתווספו בעתיד. כרגע רק מתכוני מרוקו מתויגים לחגים.'}
```

לחיצה עליו מציגה `showToast()` עם ההודעה. `title` attribute מציג את אותה הודעה כ-tooltip.

**למה Option C ולא A/B:** תיוג חגים של 270 מתכוני עדות דורש ידע אמיתי של מסורות משפחה וקהילה שלא בידי מודל AI. תיוג שגוי יפגע באותנטיות הזיכרונית של האתר. לעתיד, אסף יוכל לספק תיוגים בעצמו או בעזרת המשפחה.

**i18n:** `community_holidays_lbl`, `community_holidays_msg`

