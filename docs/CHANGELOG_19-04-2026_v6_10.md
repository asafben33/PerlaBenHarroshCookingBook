# CHANGELOG — גרסה 6.10 — 19/04/2026

**ספר הבישול של משפחת בן הראש ז״ל — החלפת `alert()` ב-Custom Modal ועדכון מלל**

---

## TL;DR

שתי בקשות ממוקדות מצילום המסך של המשתמש:

1. **"asafben33.github.io says" בכותרת הדיאלוג של הוראות ההתקנה** — מפריע ולא נראה מקצועי. זה טקסט שמוצג על ידי הדפדפן בכל `alert()` (לא ניתן לעריכה ישירה מטעמי אבטחה). הפתרון: להחליף את `alert()` ב-Custom Modal שלא מראה את זה בכלל.
2. **עדכון המלל** — ההוראות יתייחסו ל"ספר הבישול של פרלה" ולא ל-URL של הדומיין.

שתי הבקשות טופלו.

## 1. למה ה-alert הציג "asafben33.github.io says"?

זו **הגנת אבטחה של הדפדפן**. כל דיאלוג מסוג `alert()`, `confirm()`, או `prompt()` של JavaScript מקבל כותרת אוטומטית עם ה-origin (הדומיין) של האתר. זה מיועד למנוע מאתרים זדוניים להתחזות לדיאלוגים מערכתיים.

**לא ניתן לעקוף את זה** — אין API או CSS שיכולים להסתיר את הטקסט הזה. Chrome, Firefox, Safari, ו-Edge כולם מוסיפים אותו בהכרח.

**הפתרון היחיד:** לא להשתמש ב-`alert()` בכלל, ובמקום זה לבנות dialog HTML משלנו.

## 2. התיקון — Custom Modal

### CSS (חדש, ~60 שורות)

רכיב `#pwa-modal-ovl` (overlay) + `#pwa-modal-box` (dialog content):
- עיצוב תואם למודל של המתכונים (זהב/חום/קרם).
- Backdrop blur של 4px.
- אנימציית כניסה: fade-in + slide-up + scale.
- תמיכה מלאה ב-light/dark themes.
- RTL מלא (direction + text-align).
- Responsive: מקסימום 480px רוחב, פדינג נדיב.

### HTML (חדש, ~10 שורות)

```html
<div id="pwa-modal-ovl" role="dialog" aria-modal="true"
     aria-labelledby="pwa-modal-title" aria-hidden="true">
  <div id="pwa-modal-box" role="document">
    <h3 id="pwa-modal-title"></h3>
    <ol id="pwa-modal-steps" class="pwa-steps"></ol>
    <p id="pwa-modal-note" class="pwa-note" hidden></p>
    <div class="pwa-actions">
      <button type="button" class="pwa-ok" id="pwa-modal-ok">הבנתי</button>
    </div>
  </div>
</div>
```

מיוקם אחרי הכפתור `#back-top`, לפני ה-iframe/form של Web3Forms.

### JavaScript (חדש, ~50 שורות)

הוחלף:
- `alert(msg)` → `_showPwaModal(data)` עם `data = {title, steps, note}`.
- `data.steps` מכיל מערך צעדים — כל אחד מומר ל-`<li>`.
- `data.note` אופציונלי — מוצג בגוון עדין (italic + border-top).
- סגירה: כפתור OK, קליק מחוץ לתיבה, או Escape.
- accessibility: `aria-modal`, `aria-labelledby`, focus ל-OK בפתיחה, body scroll נעול.
- fallback `alert(data.title)` אם ה-DOM נשבר (defensive coding).

### טבלת השוואה

| תכונה | v6.9 (alert) | v6.10 (Custom Modal) |
|-------|--------------|----------------------|
| כותרת "origin says" | כן ✗ | לא ✓ |

| תמיכה ב-dark/light | לא ✗ | כן ✓ |
| RTL מלא | חלקי (רק טקסט) | מלא ✓ |
| אפשרויות סגירה | רק OK | OK / מחוץ / Escape ✓ |
| accessibility | פשוטה | aria-modal + focus trap |
| ניתן להוסיף עיצוב | לא | כן ✓ |

## 3. עדכון המלל

הטקסטים המעודכנים כוללים:

### לפני (v6.9)
- "בחרו 'התקן ספר הבישול…'"
- "To install Perla Cookbook…"

### אחרי (v6.10)
- "בחרו 'התקן ספר הבישול של פרלה...'"
- "Install Perla's Cookbook..."

כל 5 מסלולי הדפדפן (iOS, Android, Firefox, Safari macOS, Chrome desktop) קיבלו:
- **Title** ברור (למשל "התקנה ב-iPhone או iPad").
- **Steps** כצעדים ברורים בעברית מלאה.
- **Note** עם הסבר תוצאה (למשל "לאחר ההתקנה, 'ספר הבישול של פרלה' יופיע במסך הבית שלכם").

### דוגמה מלאה — Chrome desktop

לפני (v6.9, `alert`):
```
asafben33.github.io says

להתקנה במחשב:
1. לחצו על אייקון ההתקנה בסרגל הכתובת (מסך עם חץ)
   או פתחו את התפריט (שלוש נקודות) ובחרו "התקן ספר הבישול…"
2. אשרו "התקן"

אם האייקון לא מופיע — נסו לרענן את הדף ולחזור.

[OK]
```

```
│    (מסך עם חץ), או פתחו את התפריט       │
│    (שלוש נקודות) ובחרו "התקן ספר הבישול │

│ 2. אשרו בלחיצה על "התקן".               │
│                                         │

│ אם האייקון לא מופיע — נסו לרענן את הדף │
```

## 4. בדיקה לאחר פריסה

1. פתח את האתר בחלון incognito.
2. לחץ על כפתור "התקן" בכותרת (ליד EN/Theme).
3. **אמורה להופיע תיבת דיאלוג עם רקע מטושטש** — בלי הכותרת "asafben33.github.io says".
4. התיבה מציגה כותרת, רשימת צעדים ממוספרת, והערה בגוון עדין למטה.
5. כפתור "הבנתי" סוגר. גם קליק על הרקע סוגר. גם Escape סוגר.
6. **במצב night:** התיבה מופיעה בגוונים כהים עם זהב.
7. **במצב day:** התיבה מופיעה בגוונים בהירים עם חום כהה.

## 7. הערה על ה-origin באפשרויות אחרות

לידיעתך — ה-origin כן מופיע במקום אחד שלא ניתן לשנות:

### ה-native install dialog של Chrome
כאשר Chrome מציג את דיאלוג ההתקנה שלו (אחרי `beforeinstallprompt.prompt()`), הוא משתמש ב-**`manifest.json`**, לא בדומיין. שם האפליקציה שיוצג שם הוא `"name": "ספר הבישול של משפחת בן הראש"` (הערך הקיים ב-`manifest.json`).

### אם תרצה להחליף גם את השם ב-dialog הזה
ב-`manifest.json`, השינוי ייראה כך:
```json
{
  "name": "ספר הבישול של פרלה",
  "short_name": "פרלה",
  ...
}
```

נכון לעכשיו השאלתי — "ספר הבישול של משפחת בן הראש". מאחר שלא ביקשת במפורש לשנות את `manifest.json`, לא נגעתי בו. אם תרצה שגם שם יכתוב "ספר הבישול של פרלה" — תגיד ואשנה.
